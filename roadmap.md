# GlowLang Roadmap

GlowLang is rapidly evolving. Here is a look at what we have accomplished and what is coming next.

## Completed
*   ✅ Fast custom VM architecture with JIT compilation.
*   ✅ Natural language syntax (`when x is y`, `every`, `show`).
*   ✅ Built-in SIMD Tensors for machine learning.
*   ✅ Built-in SQLite and HTTP capabilities.
*   ✅ `gdu` package manager.

## Current Focus (Phase 6)
*   ⏳ **Hardware Acceleration**: Integrating CUDA kernel support for massive GPU-based parallel tensor operations.
*   ⏳ **Fuzzer Stability**: Ensuring the compiler and runtime gracefully handle edge-case syntax without deadlocking.

## Future Plans
*   🚀 **Ecosystem Growth**: Expanding the standard library and community packages.
*   🚀 **Language Server Protocol (LSP)**: Enhancing IDE support and autocompletion tools.
*   🚀 **Cross-Platform Binaries**: Pre-compiled releases for Windows, macOS, and Linux.
